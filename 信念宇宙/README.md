# 3D 信念宇宙（本机版）

一个只绑定到 `127.0.0.1` 的个人信念探索工具：3D 用于观察结构，2D 大纲与右侧详情用于完整编辑、证据核对、关系建立、Check-in 和备份。

## 启动

最简单的方式：双击项目根目录的 `启动信念宇宙.command`。启动器会在需要时本机构建，并在终端打印一次性会话网址；按住 `Command` 点击该网址打开网页。终端窗口需要保持打开；关闭窗口或按 `Control-C` 即停止服务。

也可在终端运行：

```bash
./启动信念宇宙.command
```

首次加载已有结构化种子：4 个价值、2 个资源性核心、3 个限制性核心、7 条条件规则、6 类保护策略、5 条桥梁信念。它们大多来自旧对话中的转引、归纳或推断，页面保留 `Q / A / I / G` 标记，不会冒充已经核对的用户原话。

## 导入与 AI 分析

1. 从 ChatGPT 获取官方数据导出 ZIP。
2. 在网页中选择“导入并核验对话”，选择 ZIP、`conversations.json` 或补充 TXT。
3. 页面先在浏览器内校验、去重并显示覆盖范围；附件不会被自动读取。可点击“仅保存来源到本机”，完全不发起 AI。
4. 只有勾选知情提示并点击“开始 AI 分析”后，对应对话文字才会经本机已登录的 Codex 发送给 OpenAI。

分析可以取消；客户端中断会终止当前 Codex 子进程。已完成批次按内容哈希缓存，后续只处理新增或变化内容。没有 API key 流程。

## 数据与隐私边界

- 图谱、原始导入和分析缓存保存于当前浏览器的 IndexedDB，不发布、不云同步、不生成分享链接。
- 浏览器数据被清理时，本地资料可能被删除。请定期点击“导出备份”；JSON 中包含未脱敏原文，应按敏感文件保管。
- 本机桥接与内部渲染器都只监听 `127.0.0.1` 随机端口；会话由一次性启动令牌和同源 HttpOnly Cookie 保护。
- Codex 分析运行在临时空目录、只读沙箱中，并禁用 shell、浏览器、电脑控制、Chronicle、Apps 与插件工具。
- 图谱是可修改的导航隐喻，不是心理诊断，也不表示信念具有客观精确坐标。

## 开发验证

项目使用 React、TypeScript、Three.js / React Three Fiber、Zustand、Zod 与 Dexie。

```bash
pnpm run typecheck
pnpm run lint
pnpm run test
```

`pnpm run test` 会运行数据导入/迁移/完整性测试、本机桥接安全测试、生产构建和渲染 HTML 检查。项目依据来自 Sites 工程骨架，但按需求不执行 Sites Hosting 或任何公共部署。
